## 第一批：BUG-1 + BUG-2 + FEAT-1（撤销机制，核心）

三个项强关联，一起实现。

### 现状

当前快捷键：`←→ 跟随GPS | . 保护 | ↑↓ 导航`
- `←`/`→`：调用 `_quick_follow_gps(visual_row, direction)` 跟随邻居GPS
- `.`：toggle 保护（`main_window.py` 约第 1523-1534 行）
- `↑`/`↓`：导航选中行
- 问题：按左右键后不可逆，没有撤销机制
- 问题：来源列（第5列，header="来源"）不可鼠标操作

### 实现清单

#### 1. 原始状态快照

`main_window.py` 的 `_populate_results` 方法中，首次填充完成后：

```python
import copy
self._original_details = copy.deepcopy(self._result_details)
```

#### 2. 撤销快捷键（Esc）

`main_window.py` 的 `keyPressEvent` 中增加 `Esc` 键处理：

```python
elif key == Qt.Key_Escape:
    self._undo_row(rows[0].row())
```

新增 `_undo_row(visual_row)` 方法：
1. 获取 data_row → 从 `_original_details[data_row]` 取原始数据
2. 恢复 `_result_details[data_row]` = copy of original
3. 刷新该行的 GPS(后)、来源、状态、备注四列
4. 刷新总览统计（`_update_stats`）

撤销应对所有状态生效：
- 跟随操作 → 恢复为匹配结果原始状态
- 保护操作 → 取消保护，恢复到保护前的值
- `. ` 的 toggle 保护仍保留（按一次保护，再按取消），Esc 作为终极撤销

#### 3. 保护 toggle 完善

当前 `.` 键的行为需要确认：
- 未保护 → 标记保护（当前逻辑）
- 已保护 → 取消保护，恢复到原始状态（需要补充）

#### 4. 提示栏更新

`result_table.py` 第 42 行：
```python
shortcut_hint = QLabel("←→ 跟随GPS | . 保护/取消 | Esc 撤销 | ↑↓ 导航")
```

## 第二批：FEAT-2（来源列鼠标交互）

依赖第一批的撤销机制。

### 实现

`result_table.py` 或 `main_window.py` 中：

1. 拦截来源列（column index=5）的双击事件
2. 弹出 QMenu，选项根据当前行状态动态生成：

```python
menu = QMenu(self)
detail = self._result_details[data_row]
method = detail.get("method", "")

# 总是显示：保护/取消保护
if method == "protected":
    menu.addAction("取消保护", lambda: self._undo_row(visual_row))
else:
    menu.addAction("保护", lambda: self._toggle_protect(visual_row))

# GPS(后) 为空时显示跟随选项
gps_after = self._results_table.item(visual_row, 4)
if gps_after and gps_after.text() in ("无", "—", ""):
    menu.addAction("跟随上一个", lambda: self._quick_follow_gps(visual_row, -1))
    menu.addAction("跟随下一个", lambda: self._quick_follow_gps(visual_row, 1))

# 已操作（非原始状态）时显示撤销
if detail != self._original_details[data_row]:
    menu.addSeparator()
    menu.addAction("撤销", lambda: self._undo_row(visual_row))
```

3. 菜单操作复用 `_quick_follow_gps`、`_undo_row`、`_toggle_protect` 方法

### 相关文件

- `main_window.py`：cellDoubleClicked 信号连接
- `result_table.py`：双击事件转发
