## 提示词

```
按 v0.13.0 迭代计划开始开发。先阅读以下文档：
- docs/v0.13.0-iteration-plan.md（版本号更新 bug）

## 唯一任务：BUG-1 版本号未随迭代更新

当前版本号停在 0.9.0，需要更新为当前开发版本。

### 修改文件

1. `pyproject.toml` 第 3 行：`version = "0.9.0"` → 更新为当前版本
2. `src/gps_photo_tracker/__init__.py` 第 3 行：`__version__ = "0.9.0"` → 同步更新

### 注意

- 版本号应与当前迭代一致
- 后续每次迭代都需同步更新这两处
- macOS 启动时的 IMKCFRunLoopWakeUpReliable 错误是系统输入法问题，与应用无关
- 修改后 `pip install -e .` 验证安装版本号正确

## 质量要求

- 修改后 `pip install -e .` 确认版本号正确
- 运行测试套件确认无回归
```
