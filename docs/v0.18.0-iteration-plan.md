# v0.18.0 迭代计划

记录于 2026-05-17。
测试版本：a10a074（v0.17.0）

## Bug 列表

### BUG-1：列表来源列不可鼠标交互

- **测试版本**：a10a074
- **现象**：结果列表中，来源列只能用键盘左右键操作（跟随上一个/下一个），无法用鼠标点击选择操作
- **期望**：鼠标双击来源列（或右键菜单），弹出操作选项
- **当前快捷键提示**：`←→ 跟随GPS | . 保护 | ↑↓ 导航`
- **修复方向**：
  - 鼠标双击来源列 → 弹出操作菜单（跟随上一个/下一个/保护/撤销）
  - 或右键上下文菜单
- **相关文件**：`result_table.py`, `main_window.py`

### BUG-2：左右键操作不可撤销

- **测试版本**：a10a074
- **现象**：按左右键跟随GPS后，按错了无法恢复原始状态
- **期望**：增加撤销操作，恢复到匹配结果原始状态
- **约束**：
  - `.` 已被"保护"功能占用，不能用于撤销
  - 撤销应对保护也生效（取消保护 = 撤销保护操作）
- **修复方向**：
  - 快捷键 `Esc` 或 `Backspace` 执行撤销
  - 首次填充列表时保存每行原始状态快照（`_original_details`）
  - 撤销 = 恢复该行到原始快照，刷新所有列
  - 保护状态也可撤销（恢复到保护前的状态）
- **相关文件**：`main_window.py`, `result_table.py`

## 功能列表

### FEAT-1：撤销操作 + 快捷键体系完善

- **需求**：引入撤销机制，完善快捷键体系
- **快捷键设计**：

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `←` | 跟随上一个 | 当前行为目标，向上找最近有GPS(后)的行 |
| `→` | 跟随下一个 | 向下找最近有GPS(后)的行 |
| `.` | 保护/取消保护 | toggle，已保护再按取消保护 |
| `Esc` | 撤销 | 恢复到匹配结果原始状态（含取消保护） |
| `↑` `↓` | 导航 | 上下移动选中行 |

- **撤销实现**：
  1. `_populate_results` 首次填充时，深拷贝 `_result_details` 到 `_original_details`
  2. `Esc` 键处理：用 `_original_details[data_row]` 恢复该行
  3. 恢复内容：GPS(后)、来源、状态、备注四列 + `_result_details` 对应条目
  4. 保护状态也通过 Esc 撤销（不单独设取消保护键，`.` 的 toggle 够用）
- **提示栏更新**：`←→ 跟随GPS | . 保护/取消 | Esc 撤销 | ↑↓ 导航`
- **相关文件**：`main_window.py`, `result_table.py`

### FEAT-2：来源列鼠标交互（双击/右键菜单）

- **需求**：来源列支持鼠标操作，补充键盘操作的不足
- **交互方式**：
  - 双击来源列单元格 → 弹出操作菜单
  - 菜单选项根据当前行状态动态显示：
    - GPS(后) 为空时：跟随上一个 / 跟随下一个
    - 已保护时：取消保护 / 撤销
    - 已操作时：撤销
    - 始终显示：保护
- **与快捷键共享逻辑**：菜单操作复用 `_quick_follow_gps` 和撤销逻辑
- **相关文件**：`result_table.py`, `main_window.py`
