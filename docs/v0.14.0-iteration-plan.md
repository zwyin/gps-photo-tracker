## Bug 列表

### BUG-1：左右箭头仍为翻图导航，未触发 GPS 跟随

- **状态**：已修复（v0.12.0 期间修复，此次确认 eventFilter 正常工作）

### BUG-2：预览结果不传递到执行（WYSIWYG 分裂）

- **状态**：已修复 — 重构为步骤引导式工作流，所见即所得
- **根因**：PREVIEW 模式结果（箭头键跟随、Review 修正、`.` 重置）不传递到 COPY/OVERWRITE 执行
- **修复方案**：三步引导流程（①预览 → ②审核 → ③执行），第三步直接从表格收集当前状态写入

### BUG-3：`.` 重置无法恢复原始匹配结果

- **状态**：已修复
- **根因**：`_result_details` 被 `_quick_follow_gps()`、`_apply_review_to_table()` 原地修改，重置读到的已是修改后的值
- **修复方案**：新增 `_original_details` 深拷贝，重置从原始数据恢复
