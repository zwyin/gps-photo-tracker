### BUG-1：中间照片插值失败后未降级到最近点匹配

当前逻辑（gps_matcher.py Step 4a）：
中间照片 + 前后两点都有 → 距离超 max_gps_distance 或时间差超 middle_time_window → 直接返回失败

期望逻辑：
中间照片 + 前后两点都有 → 距离/时间差检查失败时 → 不退出，降级到最近点匹配：
  1. 比较 prev_point 和 next_point 与 adjusted_time 的时间差，取较小的那个
  2. 检查该点时间差 ≤ middle_time_window → ✅ 就近匹配成功
  3. 时间差 > middle_time_window → ❌ TIME_DIFF

同理 Step 4a 中 time_diff 检查失败也应降级，而非直接退出。
