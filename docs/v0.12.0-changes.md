> 提交：`7155ada` | 分支：`develop` | 日期：2026-05-17

## 全局设计决策：状态三列各司其职

| 列 | 职责 | 取值 |
|---|---|---|
| **状态** | 最终结果：照片有没有 GPS？ | `成功` / `失败` / `已跳过` |
| **方式** | GPS 来源：怎么得到的？ | `插值` / `就近` / `跟随上一个` / `跟随下一个` |
| **备注** | 干预细节：人工做了什么？ | `← 跟随上一个` / `手动选点` / `Review: 跟随上一个` 等 |

规则：
- 状态列只回答"还用不用管"
- "已跟随"和"已审核"从状态列移除，归入方式列
- 自动成功 vs 人工成功由备注列区分

## BUG-1：结果列表左右箭头快速跟随无法触发

**原始反馈**：处理完成后，在结果列表中选中某行按 ← / → 快速跟随相邻 GPS，箭头键被 QTableWidget 拦截用于单元格导航。

**改动内容**：

- 在 `_build_right_panel` 中为 `_results_table` 安装 `eventFilter(self)`
- `eventFilter` 捕获 `Key_Left`、`Key_Right`、`Key_Period`，返回 `True` 阻止事件传播
- 上下箭头键保留给列表行导航（不拦截）
- `keyPressEvent` 在 MainWindow 层也保留相同逻辑作为后备

**涉及文件**：`main_window.py`

**验证方法**：处理完成后，在结果列表中选中一行，按 ← → 应触发 GPS 跟随而非单元格移动。↑ ↓ 仍正常切换选中行。

## FEAT-1：Review 对话框支持手动重新打开

**原始反馈**：初次运行完毕后 Review 对话框自动弹出，关闭后无法再次打开。

**改动内容**：

- 结果列表筛选行右侧新增"审核"按钮（固定宽度 60px）
- 按钮初始禁用，PREVIEW 模式下有失败结果时自动启用
- `_reopen_review_dialog` 方法从当前表格状态构建 ReviewState：
  - `failed_results`：遍历当前表格中 `success=False` 的行
  - `all_results`：从 `_result_details` 重建所有结果（包含之前的箭头键跟随和 Review 修改）
  - `gps_segments`：使用原始 review_data 中的 GPS 轨迹
- Review 修改后通过 `_apply_review_to_table` 回写到表格
- 多次打开/关闭不丢失已有修改
- `build_result_panel` 返回值新增 `review_btn`

**涉及文件**：`result_table.py`（按钮创建 + 返回值变更）、`main_window.py`（按钮连接 + 重开逻辑）

**验证方法**：处理完成后 Review 弹出 → 关闭 → 点击"审核"按钮 → 再次打开确认数据一致 → 修改 → 关闭 → 再次打开确认。

## FEAT-2：快捷键提示优化 + 新增 `.` 重置快捷键

**原始反馈**：需要更显眼的快捷键提示，以及"撤销"功能。

**改动内容**：

- 提示文案更新为：`←→ 跟随GPS | . 重置 | ↑↓ 导航`
- 新增 `_reset_row_gps` 方法：
  - 从 `_result_details` 恢复原始匹配结果
  - GPS(后) 列恢复为原始计算 GPS
  - 方式列恢复为插值/就近/已跳过
  - 状态列恢复为成功/失败/已跳过
  - 备注列清空
- `.` 键通过 `eventFilter` 和 `keyPressEvent` 均可触发
- `_update_stats_card` 在重置后刷新统计

**涉及文件**：`result_table.py`（提示文案）、`main_window.py`（重置逻辑）

**验证方法**：先用 ← → 跟随某行 GPS，再按 `.` 键，应恢复为原始匹配结果，备注列清空。

## FEAT-3：结果列表新增备注列

**原始反馈**：需要区分自动成功和人工成功，记录干预操作细节。

**改动内容**：

- 表格从 7 列扩展为 8 列，新增第 7 列"备注"
- 列顺序：`文件名(0) → 日期时间(1) → GPS前(2) → 计算GPS(3) → GPS后(4) → 方式(5) → 状态(6) → 备注(7)`
- 备注列使用 `Stretch` 模式，自动填充剩余宽度
- 自动备注内容：
  - 箭头键跟随 → `← 跟随上一个` / `→ 跟随下一个`
  - Review 手动选点 → `手动选点`
  - Review 输入坐标 → `手动输入坐标`
  - Review 跟随 → `Review: 跟随上一个` / `Review: 跟随下一个`
  - `.` 重置 → 清空备注
  - 自动匹配 → 空字符串

**涉及文件**：`result_table.py`（列定义）、`main_window.py`（所有备注写入位置）

**验证方法**：Review 修正后观察备注列内容，箭头键跟随后观察备注，`.` 重置后确认备注清空。
