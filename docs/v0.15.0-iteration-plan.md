## Bug 列表

### BUG-1：中间照片插值失败后未降级到最近点匹配

- **现象**：中间照片（前后 GPS 点都有）因距离/时间差过大导致插值失败时，直接标记失败退出
- **实际 case**：
  - 00463-00474（13:38~13:42）：前后 GPS 轨迹点距离超过 `max_gps_distance`，全部"距离过大"失败
  - 但这些照片离前一个成功匹配的照片只有 1-5 分钟，完全可以就近匹配
  - 需要人工 Review 跟随上/下才能补上，本应自动完成
- **当前逻辑**（gps_matcher.py Step 4a）：
  ```
  中间照片 + 前后两点都有 → 检查距离 → 超阈值 → ❌ GPS_DISTANCE（直接退出）
  ```
- **期望逻辑**：
  ```
  中间照片 + 前后两点都有 → 检查距离
    → 距离 OK → 插值
    → 距离过大 → 降级：取时间差小的那个轨迹点，做最近点匹配
      → 时间差 ≤ middle_time_window → ✅ 就近匹配
      → 时间差 > middle_time_window → ❌ TIME_DIFF
  ```
- **同理**：时间差过大（`time_diff > middle_time_window`）也应降级到最近点，而非直接失败
- **测试数据**：`test-data/debug_input/照片 GPS 追踪记录（2026-02-07）.md`
- **相关文件**：`gps_matcher.py` Step 4a 分支

## 功能列表

### FEAT-1：结果列表导出功能

- **需求**：主界面结果列表支持导出为文件（CSV/Markdown），方便用户做问题对齐和 debug
- **场景**：遇到匹配问题时，用户目前需要手动截图+提取内容来反馈，效率低
- **导出要求**：
  - 字段、内容、顺序与列表显示**完全一致**（所见即所导）
  - 包括列头名称、GPS 格式、方式文本、状态文本、备注内容
  - 当前列表有几列就导出几列，不增不减
- **交互**：结果列表区域增加"导出"按钮
- **格式**：CSV 或 Markdown 表格（用户可选）
- **相关文件**：`main_window.py`, `result_table.py`
