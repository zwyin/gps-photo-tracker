## Bug 列表

### BUG-1：Review 应用后 GPS 列高亮不一致

- **场景**：Review 对话框选择"应用所有建议"后，回到主界面结果列表
- **涉及模式**："跟随上一个" / "跟随下一个"
- **现象**：GPS前（原坐标）有颜色标注，GPS后（修改后坐标）没有颜色标注
- **示例**：某照片 GPS前 X,Y 有颜色 → 计算GPS为空 → GPS后 X,Y 无颜色
- **期望**：GPS前后应有对称的颜色高亮，直观体现坐标变化
- **相关文件**：`src/gps_photo_tracker/gui/result_table.py`

### BUG-4：孤立照片匹配缺陷 + match_tail 命名误导

- **三种孤立场景**（逻辑应完全一致，统一处理）：
  1. **头部孤立**：照片拍摄时间早于 GPS 轨迹段起点
  2. **尾部孤立**：照片拍摄时间晚于 GPS 轨迹段终点
  3. **中间孤立**：照片在轨迹段范围内，但前后邻居照片间距超过 context_window
- **现象**：`_find_segment()` 仅匹配 `seg.start ≤ ts ≤ seg.end`
  - 头部和尾部照片直接返回 `NO_GPS_COVERAGE`，无法进入孤立匹配分支
  - 中间孤立照片可以进入孤立匹配（因为时间在段内）
  - 三种场景处理不一致，头部和尾部被不公平排除
- **附带问题**：`match_tail` 参数名暗示只处理尾部，实际控制所有孤立场景，命名误导
- **修复方案**：
  1. 重命名：`match_tail` → `match_isolated`，`RejectReason.TAIL_ISOLATED` → `ISOLATED_DISABLED`
  2. 修改 `_find_segment()` 逻辑：找不到精确覆盖段时，查找时间最近的轨迹段（在 `isolated_window` 容差内），使头部/尾部照片也能进入孤立匹配分支
  3. 孤立匹配逻辑不变：取最近 GPS 点，检查 `isolated_window` 时间阈值
  4. GUI 参数标签同步更新
- **影响范围**：
  - `core/gps_matcher.py`：匹配逻辑 + 变量名
  - `core/models.py`：`MatcherConfig`、`RejectReason`
  - `gui/main_window.py`：参数 UI 控件
  - 所有引用 `match_tail` 的地方
- **测试要求**：单元测试覆盖头部/尾部/中间孤立三种场景 + 端到端验证
- **相关文件**：`gps_matcher.py`, `models.py`, `main_window.py`, 所有测试文件

### BUG-5：已有 GPS 照片未跳过匹配，被错误标记为失败

- **场景**：参数"覆盖已有GPS"未勾选时，照片已有 GPS 坐标
- **期望行为**：这些照片应完全跳过匹配流程，保留原 GPS，状态应为"已跳过"或类似标识，不计入失败数
- **当前行为**：
  - `GPSMatcher` 不检查 `has_gps`，所有照片都走匹配流程
  - `overwrite_gps` 只在 GUI 层控制显示（main_window.py 第 572-577 行）
  - 已有 GPS 的照片如果匹配失败，仍被标记为失败，计入失败统计
- **修复方案**：
  - 在 `GPSMatcher.match()` 入口过滤：`overwrite_gps=False` 时跳过 `has_gps=True` 的照片
  - 跳过的照片返回 `MatchResult(success=True, method="skipped")` 或新增 `SkipResult`
  - GUI 层对跳过照片显示"已跳过"状态，不计入失败数
  - 总览统计中区分：成功 / 跳过 / 失败
- **相关文件**：`gps_matcher.py`, `main_window.py`, `result_table.py`

### BUG-6：Review 修正后成功率统计未更新

- **场景**：匹配失败的照片经 Review 修正（跟随上/下、手动选点等），GPS 已回写到列表
- **现象**：修正后的照片仍按原始失败状态计入统计，成功率未体现人工干预效果
- **期望**：成功率先分两个阶段展示：
  - 成功率-初始：程序自动匹配结果（如 64/65 = 98.5%）
  - 成功率-最终：人工干预后的最终结果（如 65/65 = 100%）
- **示例**：65 张照片，自动匹配 64 张成功，1 张失败经 Review 修正 → 最终 100%
- **相关文件**：`main_window.py`, `result_table.py`
