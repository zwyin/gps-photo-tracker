# v0.14.0 Changes

## Theme: WYSIWYG Step-Based Workflow

Redesigned the main workflow from radio-button mode selection (PREVIEW/COPY/OVERWRITE) to a step-based guided flow. Preview results now carry forward to execution — what you see is what gets written.

## Changes

### 1. Step-Based UI (config_panel.py)

- Replaced `build_mode_group()` (radio buttons) with `build_step_group()` returning 4 buttons:
  - **① 预览匹配** — Scan + match preview
  - **② 审核** — Open review dialog for failed matches
  - **③ 拷贝** — Copy photos to output with GPS tags
  - **③ 覆盖** — Overwrite original photos with GPS tags

### 2. Main Window Refactor (main_window.py)

- **`_original_details`**: Deep copy of initial match results, used by `_reset_row_gps()` for true reset
- **`_on_step1_preview()`**: Step 1 handler (scan + match)
- **`_on_step2_review()`**: Step 2 handler (opens review dialog)
- **`_on_step3_execute(mode)`**: Step 3 handler — collects table results and launches Worker
- **`_collect_table_results()`**: WYSIWYG — reads GPS(后) column directly from table to build `MatchResult` list
- Removed: `_on_start()`, `_build_buttons()`, mode radio button handling

### 3. Worker Direct Write (worker.py)

- Added `pre_computed_results` parameter
- When provided, Worker skips scan+match and calls `service.write_phase()` directly
- Removed: `review_decisions`, `_apply_stored_review()`, three-path logic

### 4. COPY Output Directory (tagging_service.py)

- `_copy_destination()`: Flat photo directories now wrap output under `photo_dir.name` subdirectory
  - Example: `input/0207/photo.jpg` → `output/0207/photo.jpg` (instead of `output/photo.jpg`)
  - Nested directory structures preserved as before
- `_write_photo()`: Added `dst.parent.mkdir(parents=True, exist_ok=True)` for COPY mode

### 5. Test Updates

- `test_gui.py`: Updated for new button structure (`_step1_btn`, `_step2_btn`, etc.)
- `test_service.py`: Updated path assertions for new directory structure
- `test_review.py`: Replaced `TestWorkerApplyStoredReview` with `TestWorkerDirectWrite`
- `test_review_flow.py`: Updated output paths to include `tmp_path.name`
